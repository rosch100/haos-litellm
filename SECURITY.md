# Security Policy

## Supported versions

Only the default branch and the latest published app version receive security
fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/rosch100/haos-litellm/security/advisories/new).
Include the affected version, impact, reproduction steps, and any suggested
mitigation. Do not create a public issue or disclose the vulnerability before
we have coordinated a fix.

We will acknowledge a report as soon as practical, investigate its impact, and
coordinate a fix or mitigation before public disclosure.
